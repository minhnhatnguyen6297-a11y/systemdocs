# Soát văn bản độc lập

Cửa vào: [SPEC module](../../SPEC.md).
**Đổi chức năng soát văn bản: sửa phần nghiệp vụ trong [technical.md](technical.md)**
(file giữ tên cũ theo bảng định tuyến). Chi tiết kỹ thuật không đặt lại công nghệ.

Công cụ độc lập với web OCR/Stage, không tự chạy sau mỗi lần xuất Word.
Đọc source hiện tại và kiểm chứng trước khi tuyên bố khả năng hoặc kết quả test.
